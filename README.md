# Учёт успеваемости студентов

Веб-приложение для хранения данных о студентах, ведения учебных планов и журнала оценок. Сервер написан на Go, данные хранятся в PostgreSQL. Интерфейс — HTML-шаблоны Go и CSS.

## Возможности

- **Студенты:** добавление и редактирование ФИО, года поступления, группы и формы обучения — дневной, вечерней или заочной.
- **Специальности и дисциплины:** создание и изменение справочников.
- **Учебные планы:** привязка дисциплин к специальностям с указанием семестра, количества часов и формы контроля — экзамена или зачёта.
- **Журнал оценок:** запись и изменение оценок по студенту, дисциплине, учебному году и семестру. Поддерживаются оценки от 2 до 5, зачёт и незачёт.
- **Отчёты:** подсчёт студентов по форме обучения и просмотр часов и форм контроля по выбранной дисциплине.

## Запуск через Docker

Нужен установленный и запущенный Docker с Docker Compose. Устанавливать Go и PostgreSQL отдельно не требуется. Порт `8080` должен быть свободен.

Из корня проекта выполните:

```bash
docker compose up --build
```

При первом запуске Docker скачает образы, соберёт приложение и создаст базу данных по схеме из `db/init.sql`. После запуска откройте [http://localhost:8080](http://localhost:8080).

Для запуска в фоне:

```bash
docker compose up --build -d
```

Просмотр логов приложения:

```bash
docker compose logs -f app
```

Остановка:

```bash
docker compose down
```

Данные сохраняются в Docker-томе `postgres_data` и остаются после остановки. Скрипт `db/init.sql` выполняется только при создании новой базы.

## Запуск без PostgreSQL

Из корня проекта с установленным Go:

```bash
go run ./cmd/api --self
```

При запуске без `DATABASE_URL` или после одной неудачной попытки подключения к PostgreSQL приложение тоже использует память и пишет `self mode` в лог. Данные в этом режиме пропадают при перезапуске.

## Как пользоваться

1. Добавьте студентов, специальности и дисциплины на главной странице.
2. В разделе «Дисциплины в планах» укажите дисциплины для каждой специальности, семестры, часы и формы контроля.
3. Заполняйте «Журнал оценок», выбирая студента и дисциплину.
4. Для изменения записи используйте ссылку «Изменить» в соответствующей таблице.
5. В разделе «Отчёты» выберите форму обучения или дисциплину и отправьте форму.

## Структура проекта

```text
cmd/api/              — запуск сервера
internal/domain/      — модели данных
internal/handler/     — HTTP-обработчики и рендеринг страниц
internal/service/     — бизнес-логика и проверка данных
internal/repository/  — запросы к PostgreSQL
db/init.sql           — таблицы и SQL-функции для отчётов
web/                  — HTML-шаблон и CSS
compose.yaml          — запуск приложения и базы данных
```

Параметры подключения задаются в `compose.yaml`: `DATABASE_URL` — строка подключения к PostgreSQL, `ADDR` — адрес HTTP-сервера (по умолчанию `:8080`).
